# 0005. 1979-80 as the backfill start season

**Status:** Accepted

## Context

The backfill needed a start season. Going back to the NBA's founding would
mean modeling eras with no play-by-play, minimal box scores, and rules
(no three-point line) different enough that most derived metrics would not
be comparable to the modern game. An arbitrary recent cutoff would be
easier to backfill completely but would understate how much history the
platform actually covers.

## Decision

Backfill from the 1979-80 season, the first season of the NBA's
three-point line, so the platform covers the complete three-point era
rather than an arbitrary cutoff. The platform currently covers all 47
seasons from 1979-80 through 2025-26 (`README.md:7`, `README.md:177`).

## Consequences

This gives the dashboard a clean, defensible scope ("the entire
three-point era") instead of an unexplained start year, and it means
modern three-point-driven metrics are comparable across the platform's
full range. The trade-off is that box scores are incomplete before
1985-86 - 1979-80 specifically has no field goal attempts, rebounds, or
assists - so `mart_player_season.sql` and `mart_team_season.sql` both
compute an explicit `box_score_complete` flag (`incomplete_games = 0`) and
withhold derived metrics that would otherwise be computed from partial
data, rather than silently producing numbers from incomplete box scores.
Revisiting the pre-1985-86 gap would require backfilling complete box
scores from a source other than `nba_api`, which does not have them.
